# Reglas persistentes de Claude Code

## Catálogos Raíces Regalos — protocolo obligatorio
Ante cualquier catálogo, dossier o PDF comercial de productos de Raíces:
1. Leer y aplicar .claude/skills/catalogo-editorial-raices/SKILL.md y sus referencias.
   Es obligatorio incluso si el prompt no menciona la skill por nombre.
2. Combinar, si están disponibles, las skills oficiales pdf, canvas-design y frontend-design.
3. Usar solo fotos reales autorizadas y SKU, títulos y fuentes verificables.
   Nunca inventar productos, conjuntos, variantes, precios ni grabados.
4. Para un catálogo SIN PRECIOS, omitir precios por completo y validar SKU/foto/fuente
   sin exigir datos de precio. El validador completo de precios se aplica a catálogos con precios.
5. Realizar prueba editorial, renderizar e inspeccionar todas las páginas, auditar datos,
   mostrar vista previa y pedir aprobación final.
6. NO reemplazar ni publicar el catálogo actual; NO enviarlo por email, WhatsApp ni
   actualizar sistemas o tiendas sin autorización explícita posterior del usuario.
7. Mantener costo adicional cero; no exigir una PC. Trabajar en entornos autorizados.
