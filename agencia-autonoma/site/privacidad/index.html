Privacidad y tratamiento de datos

Última actualización: 23 de octubre de 2026. Responsable de este sitio: operador de Autónoma Dev, Argentina. Contacto de privacidad: formulario de consultas, indicando «Privacidad».

Datos recogidos

Nombre, correo, empresa opcional, tipo de servicio, presupuesto aproximado, descripción de la solicitud, fecha de consentimiento y registros técnicos para combatir el abuso. No solicitamos tarjetas, contraseñas ni documentos de identidad.

Finalidad y base del tratamiento

Usamos estos datos exclusivamente para revisar la consulta, preparar propuestas si corresponde, comunicarnos con quien consulta y proteger el sitio frente a envíos abusivos. El consentimiento se presta marcando la casilla del formulario. No vendemos datos ni enviamos publicidad masiva.

Dónde se almacenan

Los datos de las consultas remitidas mediante este sitio se almacenan en una base PostgreSQL de Neon, con infraestructura fuera de Argentina; la web está alojada en Render. Se aplican validaciones de entrada y acceso de servidor. No publicamos registros de consultas en la web.

Conservación

Las consultas se conservarán sólo durante el tiempo necesario para gestionarlas, atender posibles reclamos y cumplir obligaciones legales. Antes de establecer conservación y eliminación automáticas se definirá un plazo operativo por categoría; mientras tanto, puede solicitarse la eliminación de una consulta no sujeta a obligaciones legales.

Derechos

Conforme a la Ley 25.326 de Argentina puedes solicitar acceso, rectificación, actualización o supresión cuando corresponda. Envía tu solicitud por el formulario de contacto, comenzando la descripción con «Privacidad». Podremos solicitar una verificación razonable de identidad antes de divulgar datos personales.
